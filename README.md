# StageLab｜胡桃夹子：镜框背后

跟着 Clara 的旅途，认识镜框式剧场的构造与舞台机械：台口、主幕与遮蔽、舞台塔与平衡重吊杆、侧台与候场、幕间换景、台仓与乐池升降台。研究底本是太平洋西北芭蕾舞团（PNB）的 George Balanchine’s The Nutcracker（Ian Falconer 舞美，2015 年首演），演出场所为西雅图 McCaw Hall。界面与沙盘沿用《哈姆雷特：舞台流变》V3。

## 打开方式

这是放在 GitHub Pages 上的网页版。上传到 GitHub 并开启 Pages 后，用 `https://你的用户名.github.io/仓库名/` 打开即可（Chrome 或 Edge，需要联网）。

`index.html` 必须位于仓库最外层，旁边是 `src`、`assets`、`productions` 三个文件夹。页面需要 WebGL2。

以后修改了文件，在仓库里重新上传同名文件即可，GitHub 会在一两分钟内自动更新网页；浏览器若还显示旧版本，按 Ctrl+F5 刷新。

## 九个段落

| 段落 | 剧情 | 后台揭示与知识卡 |
|---|---|---|
| 1 开演 | 序曲、乐池、主幕升起、走廊纱幕退去，家宅出现 | 台口高亮，镜头拉远看整座剧场 → **01 台口与主舞台** |
| 2 获得礼物 | 家宴，德罗塞尔迈尔送出胡桃夹子玩偶 | 只建立人物，不出卡 |
| 3 房间变大 | 午夜，树和家具变大，树顶越过台口 | 前台“变化前／变化后”对比 → **02 布景与剧场** |
| 4 帮助取胜 | 老鼠与玩具兵交战，Clara 掷鞋，王子出现 | 压缩为几个动作 |
| 5 穿过雪林 | 雪花舞者，纸雪落下 | 台口墙剖开，看雪袋与吊杆操作区；学生拖动摇晃雪袋；绳索高亮 → **03 舞台塔与吊挂** |
| 6 幕间换景 | 第一幕结束 | 主幕落下 → **04 幕与遮蔽**；幕后扫雪、转换前后对照、四步条 → **05 幕间换景** |
| 7 糖果国 | 糖果仙子、杏仁糖之舞 | 点击“侧台 · 候场”进入侧台：五人穿裙、架子承重、卡扣、舞台监督、八个孩子；点击“出场” → **06 侧台与候场** |
| 8 告别 | 驯鹿雪橇飞离，幕落 | 只看观众看见的结果 |
| 9 回看剧场 | 整座剧场剖面 | 依次点开上方（平衡重演示）、侧面（布景升降机）、台下（台板下沉）、乐池（三档升降） → **07 乐池与台下**，结尾剧场地图 |

完整播放约 8 分钟（不含教师停留与阅读）。

## 配乐

每一段都有配乐，依据柴可夫斯基《胡桃夹子》（1892，公有领域）改编，用 WebAudio 实时合成（弦乐、拨弦、钢片琴、长笛、铜管、竖琴、定音鼓，加音乐厅混响），不需要任何音频文件。

| 段落 | 配乐 |
|---|---|
| 开演 | 轻快的序曲（降 B 大调，弦乐跳弓与拨弦） |
| 获得礼物 | 家宴进行曲（G 大调，铜管号角与弦乐应答）；夜深转为钢片琴夜曲 |
| 房间变大 | 把大双人舞的下行音阶倒过来，随着树长高一级级上行，定音鼓滚奏 |
| 帮助取胜 | D 小调战斗段落：低音弦乐快速音型、铜管和弦与定音鼓 |
| 穿过雪林 | E 小调雪之圆舞曲：长笛旋律、竖琴分解和弦、人声般的和声 |
| 幕间换景 | 安静的钢片琴与弦乐 |
| 糖果国 | 糖果仙子之舞开头的钢片琴动机与同音反复的半音下行；姜饼妈妈出场时换成活泼的二拍子 |
| 告别 | 大双人舞主题：从 G 往下走的 G 大调音阶 |
| 回看剧场 | 同一主题，由钢片琴与竖琴轻声奏出 |

**换成真实录音：** 把 mp3 放进 `assets/music/`，在 `productions/music.js` 里登记（例如 `sugar: 'assets/music/sugar.mp3'`），对应段落会优先播放录音，其余段落继续使用合成配乐。请使用你有权在课堂播放的录音。打开知识卡（剧情暂停）时，音乐会自动压低。

## 课堂操作

- 点击出现在画面中的引导句推进互动；Enter 可代替点击，也可替学生完成“摇雪袋”和“对照”。
- 拖动沙盘旋转，滚轮缩放；空格暂停／继续。
- 左右箭头切换段落，R 重看本段，数字 1–9 直接跳段。
- I 打开资料与操作说明，A 打开当前知识卡，Esc 关闭。打开知识卡会暂停剧情，关闭后恢复原来的播放状态。
- 地址可加 `?scene=5&auto=1&speed=2`，用于跳段、自动触发互动、倍速演示；`?q=low` 降低画质。

## 人物与动画

人物按真实比例建模（成人约七个半头身，孩子头部略大）：头部带眼睛、眉毛、鼻子和嘴，有颈、胸、腹，手臂分上臂和前臂、有肘关节，腿分大腿和小腿、有膝关节和脚。走路时摆动的腿会屈膝，手臂与腿反向摆动，髋部轻微摆动；静止时有呼吸起伏；旋转平滑起停；芭蕾手位时肘部自然弯曲；坐下时先转身再坐。所有走位都沿路线绕开家具与景物，从景片上的门、侧幕之间的空隙进出。

渲染器使用实例化绘制：同一种几何体每一遍只发一次绘制命令（每帧约 20 次），老电脑与集成显卡也能流畅播放。

## 证据边界

知识卡正文用四种小标签区分资料性质（教师用的说明，不是学生要背的分类）：

- **制作事实**：来源直接记录的效果、设备或人员工作。雪袋（三条约 50 英尺长的帆布，一侧开孔，装白色碎纸，由吊杆组摇动）、幕间三人道具组扫雪、姜饼妈妈的穿裙与出场准备、后台人数，均来自 PNB 舞台监督 2024 年的说明。
- **场所资料**：McCaw Hall 技术资料（2022 修订）中的台口、栅顶、吊杆、幕布库存、搬运区、升降机、台仓与乐池数据。它说明剧场“有什么”，不等于这一版用过。
- **教学编排**：镜头、简化小人、互动控制、压缩时长；景物在状态之间的“叠化”；台口墙的半透明“剖开”。
- **待核查**：圣诞树的生长机构、结尾飞行的机构、每件景的进出路线与原版 cue、侧台方向与站位、雪袋的具体吊法。沙盘不为这些内容编造机械。

画面字幕只写剧情和有资料的事实，不出现“资料没有记录”一类的说明，也不出现“看这里、试一试”一类的引导语——这些留给教师在课堂上讲。资料边界写在知识卡的详细页里，供教师查阅。剧情字幕是教学概括，不是原版台词。服装与舞美配色参考公开影像与报道的大致色调，形状和尺寸都不是原设计图。

## 修改入口

- `productions/data.js`：七张知识卡的正文、证据标签与来源（P1–P10、Q1–Q3、G1–G2）。
- `productions/music.js`：登记可选的真实录音。
- `src/audio.js`：合成乐器与各段配乐的乐谱（音名记谱，可直接改）。
- `src/story.js`：九段剧情、镜头、灯光、互动与知识卡弹出时机。
- `src/world.js`：剧场建筑、吊杆与配重、三套布景、纸雪模拟、雪橇。
- `src/figures.js`：人物、服装、大裙子、扫帚与玩偶。
- `src/ui.js`、`src/text.js`、`src/style.css`：卡片、关系示意图、工具面板、字幕与界面。
- `tools/build_standalone.py`：需要断网备用时，运行 `python tools/build_standalone.py` 生成离线单文件，无第三方依赖。
- `tools/subset_fonts.py`：改了中文文案后重新生成字形子集（需要 fontTools 与 Noto CJK 字体）。

`tween.js` 与《哈姆雷特》V3 相同；`engine.js` 在其基础上改为实例化绘制，并增加了裙身、头部、芭蕾短裙三种几何体。

## 验证范围

已用 Chromium（软件 WebGL）检查：本地文件打开、九段自动连续播放到结尾、七张知识卡按顺序解锁、九段跳段、知识卡打开暂停与关闭恢复、桌面与窄屏布局，以及离线单文件。配乐的乐谱长度与运行已检查，但无法在测试环境里试听，请上课前戴耳机听一遍，音量可用 M 键开关。字体为 Noto Sans／Serif CJK 的字符子集，OFL 许可见 `assets/fonts/`。
